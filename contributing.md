# Contribution Guidelines

Open a pull request that adds one entry, at the bottom of the section it belongs in:

```md
- [package-name](https://github.com/owner/repo) - Types Foo files.
```

- The package is a content mapper that works today, or a tool or resource for building one.
- Link the GitHub repository, or the package's directory in a monorepo. Link npm only when the source isn't public.
- The description is one short sentence that says what the package types. It starts with a capital letter and ends with a period.
- One entry per pull request.
